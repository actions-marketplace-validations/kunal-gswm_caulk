# Security Policy

The Caulk project takes the security of our software and users seriously.

## Supported Versions

| Version | Supported          |
| :------ | :----------------- |
| 0.3.x   | :white_check_mark: |
| < 0.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in Caulk, please report it responsibly.

### Preferred Reporting Method

Please report vulnerabilities privately via **GitHub Private Vulnerability Reporting**:

1. Navigate to the Caulk repository on GitHub: [https://github.com/kunal-gswm/caulk](https://github.com/kunal-gswm/caulk)
2. Click the **Security** tab.
3. Select **Report a vulnerability** under "Vulnerability reporting".
4. Provide a detailed summary, including:
   - Steps to reproduce or proof-of-concept repository.
   - Operating system and Python version.
   - Impact of the issue.

### Guidelines

- **Do not open public GitHub issues** for suspected security vulnerabilities.
- Allow maintainers reasonable time to investigate, reproduce, and release a patched version before public disclosure.
- When creating synthetic proof-of-concept repositories, **never** include real credentials, private keys, or personal data.
